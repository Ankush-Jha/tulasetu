## mermaid/
Four diagrams, white background, civic blue / brass accent palette (matches the impact brief). Paste each `.mmd` file's contents into https://mermaid.live, export as PNG/SVG at your preferred size.

- `01-workflow-before-after.mmd` — desk-to-desk vs direct-to-person, side by side
- `02-report-lifecycle.mmd` — the statutory Draft → Published state machine
- `03-engine-architecture.mmd` — one computed dataset → PDF / DOCX / JSON
- `04-rbac-chain.mmd` — MA → AD/DD → Director, the three-role approval chain

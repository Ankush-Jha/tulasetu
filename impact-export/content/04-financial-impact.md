# Financial impact — real mechanisms, no invented ROI number

| Mechanism | Type | Basis |
|---|---|---|
| Avoided resubmission on a miscalculated verdict — fresh application, fresh testing fee | Direct saving | ₹10,000 (mechanical) / ₹25,000 (digital-electronic) per rejected model, Rule 19 & Rule 10, AoM Rules 2011 |
| Officer hours reclaimed from manual arithmetic re-verification at AD/DD stage | Labour saving | The PS's own diagnosis: manual checking is why the process is "time-consuming" |
| Rule 4(9) annual statistical return generated on demand instead of hand-compiled | Statutory efficiency | A legally mandated report produced as a side-effect, not a separate task |
| Workload rebalancing made visible — a 10x gap between the busiest and quietest RRSL becomes a dashboard fact, not folklore | Planning value | Guwahati 3–8 vs Varanasi 40–76 models/yr, DoCA AR performance tables |
| Faster gate → faster route to a state manufacturing/import licence, which the model-approval certificate is a precondition for | Time-to-market | LM Act s.22; AoM Rules 2011 Rule 20 |
| One engine reused for in-service / state verification later (in-service mpe = 2x initial, same resolver) | Compounding value | Architecture already supports it — CLAUDE.md §5, roadmap V2 |

**No projected rupee-crore figure is used anywhere.** Every row above ties to a specific rule, a specific fee, or a specific number already verified in `docs/PRD.md`. If a judge asks for a total ₹ saved per year, the honest answer is: it scales with the ~645 certificates/year run-rate and the fraction of those that currently fail on a calculation error — a number not published anywhere and not safe to guess.
